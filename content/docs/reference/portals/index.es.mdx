career-ops escanea estos sistemas de gestión de candidaturas a través de sus API públicas de ofertas, así que el escaneo en sí no consume tokens de IA. Cada página explica qué hace el escáner, cómo habla career-ops con ese sistema y los detalles que conviene conocer.

- **[Greenhouse](/es/docs/reference/portals/greenhouse)** — career-ops consulta directamente la API pública de boards de Greenhouse. Sin scraping de HTML, sin riesgo de rate limits y sin consumir tokens de IA durante el propio escaneo.
- **[Ashby](/es/docs/reference/portals/ashby)** — Ashby es el ATS moderno preferido por las startups Serie A–C del espacio de la IA y las dev-tools. career-ops consulta directamente la API pública de su job board.
- **[Lever](/es/docs/reference/portals/lever)** — Lever es el ATS consolidado entre las empresas mid-market y en fase de crecimiento. career-ops consulta directamente la API pública de postings de Lever.

Para escanear todos a la vez, consulta [Escanea portales de empleo](/es/docs/introduction/guides/scan-job-portals).
