career-ops parcourt ces logiciels de recrutement via leurs API publiques d'offres, si bien que le scan lui-même ne consomme aucun jeton d'IA. Chaque page explique ce que fait le scanner, comment career-ops dialogue avec ce système et les points d'attention à connaître.

- **[Greenhouse](/fr/docs/reference/portals/greenhouse)** — career-ops interroge directement l'API publique des boards Greenhouse. Pas de scraping HTML, aucun risque de rate limit, et aucun token d'IA consommé pendant le scan lui-même.
- **[Ashby](/fr/docs/reference/portals/ashby)** — Ashby est l'ATS moderne privilégié par les startups en Série A–C dans l'univers de l'IA et des dev-tools. career-ops interroge directement l'API publique du job board.
- **[Lever](/fr/docs/reference/portals/lever)** — Lever est l'ATS établi pour les entreprises du mid-market et en phase de croissance. career-ops interroge directement l'API publique de postings de Lever.

Pour les scanner tous d'un coup, voir [Scanner les portails d'emploi](/fr/docs/introduction/guides/scan-job-portals).
