## O que faz

O provider greenhouse, em providers/greenhouse.mjs, faz requisições HTTP para boards-api.greenhouse.io/v1/boards/`{slug}`/jobs e converte a resposta JSON para o formato de vaga do career-ops. O slug é o identificador do board da empresa no Greenhouse (por exemplo, 'anthropic' para a Anthropic).

## Quando usar

Use a varredura do Greenhouse quando as empresas que você tem em vista usam o Greenhouse como ATS. É o caso da maioria das empresas de tecnologia dos Estados Unidos com 50 a 10.000 funcionários. O templates/portals.example.yml já vem com boards do Greenhouse pré-configurados, prontos para você ativar.

## Exemplo

```yaml title="portals.yml"
- name: Anthropic
  careers_url: https://job-boards.greenhouse.io/anthropic
  enabled: true
```

A próxima varredura passa a encontrar todas as vagas abertas da Anthropic.

## O que o scanner faz

O scanner lê no portals.yml os slugs do Greenhouse que você ativou, chama a API pública de boards para cada um e adiciona ao seu pipeline as vagas novas cujo título corresponde ao que você procura, sem scraping e sem gastar nenhum token de LLM na coleta. Uma única execução de `node scan.mjs` cobre seus boards do Greenhouse, Ashby e Lever de uma vez só e depois filtra os resultados pelas palavras-chave de título que você configurou.

```bash title="Terminal"
node scan.mjs
```

## Como o career-ops se comunica com o Greenhouse

O career-ops consulta `boards-api.greenhouse.io/v1/boards/{slug}/jobs?content=true` e lê o array `jobs` do JSON, extraindo de cada vaga o título, o `absolute_url`, a localização e a descrição completa, que chega na mesma resposta, então não é preciso fazer uma requisição por vaga. Quando um board informa a localização de uma vaga apenas como modelo de trabalho, como Remote, o career-ops faz mais uma requisição à lista de escritórios do board para acrescentar os nomes dos escritórios. A varredura em si é um simples GET via HTTPS em um endpoint público, e é por isso que ela se mantém dentro dos limites de requisições e não gasta tokens do modelo. Rodar a varredura de novo é seguro: cada URL é deduplicada em relação ao seu histórico de varreduras, às candidaturas que você já avaliou e ao pipeline atual, então uma vaga que você já viu nunca é adicionada duas vezes.

## Pontos de atenção

Como cada vaga chega com a descrição completa, os filtros de conteúdo do `portals.yml` (`content_filter`, `visa_filter` e a elegibilidade por país) leem o texto integral da vaga nos boards do Greenhouse, não só o título. Um board grande gera uma única resposta grande em vez de muitas pequenas.
