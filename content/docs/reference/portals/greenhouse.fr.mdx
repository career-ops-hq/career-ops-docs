## Ce qu'il fait

Le provider greenhouse, dans providers/greenhouse.mjs, effectue des requêtes HTTP vers boards-api.greenhouse.io/v1/boards/`{slug}`/jobs et convertit la réponse JSON au format de listing de career-ops. Le slug est l'identifiant du board Greenhouse de l'entreprise (par exemple 'anthropic' pour Anthropic).

## Quand l'utiliser

Utilisez le scan Greenhouse lorsque vos entreprises cibles utilisent Greenhouse comme ATS. C'est le cas de la plupart des entreprises tech américaines de 50 à 10 000 employés. templates/portals.example.yml est livré avec des boards Greenhouse préconfigurés que vous pouvez activer.

## Exemple

```yaml title="portals.yml"
- name: Anthropic
  careers_url: https://job-boards.greenhouse.io/anthropic
  enabled: true
```

Le scan suivant récupère alors tous les postes ouverts chez Anthropic.

## Ce que fait le scanner

Le scanner lit les slugs Greenhouse activés dans votre portals.yml, appelle l'API publique des boards pour chacun d'eux, et ajoute à votre pipeline les nouveaux postes dont le titre correspond — sans scraping et sans dépenser le moindre token LLM pour la récupération. Une seule exécution de `node scan.mjs` traite vos boards Greenhouse, Ashby et Lever en une passe, puis filtre les résultats selon les mots-clés de titre que vous avez configurés.

```bash title="Terminal"
node scan.mjs
```

```txt title="Output"
Companies scanned:     12
Total jobs found:      58
Filtered by title:     49 removed
Duplicates:            6 skipped
New offers added:      3

New offers:
  + Anthropic | Applied AI Engineer | San Francisco, CA
  + Intercom | AI Product Engineer | Dublin, Ireland
  + Vercel | Forward Deployed Engineer | Remote
```

## Comment career-ops communique avec Greenhouse

career-ops interroge `boards-api.greenhouse.io/v1/boards/{slug}/jobs?content=true` et lit le tableau `jobs` du JSON, en récupérant le titre de chaque poste, son `absolute_url`, sa localisation et sa description complète, qui arrive dans la même réponse : il n'y a donc aucune requête par poste. Lorsqu'un board n'indique la localisation d'un poste que sous la forme d'un mode de travail, comme Remote, career-ops effectue une requête supplémentaire vers la liste des bureaux du board pour ajouter le nom des bureaux. Le scan lui-même est un simple GET HTTPS vers un endpoint public, ce qui explique qu'il reste dans les limites de débit et ne consomme aucun token de modèle. Relancer le scan est sans risque : chaque URL est dédupliquée par rapport à votre historique de scan, vos candidatures déjà évaluées et le pipeline en cours, si bien qu'un poste déjà vu n'est jamais ajouté deux fois.

## Points d'attention

Comme chaque annonce arrive avec sa description complète, les filtres de contenu de `portals.yml` (`content_filter`, `visa_filter` et l'éligibilité par pays) lisent l'intégralité du texte de l'offre sur les boards Greenhouse, et pas seulement le titre. Un board volumineux produit une seule réponse volumineuse plutôt que de nombreuses petites.
