career-ops is open source (MIT) and free for candidates, and a large part of what it does was written by the people who use it. This page lists what the community has built on it: plugins that add job sources, search and exports, and job boards for markets beyond the companies' own career pages.

## Community plugins

A plugin is a separate repository that career-ops loads through hooks: `provider` adds a job source, `search` adds a search engine, `ingest` brings data in (job alerts, calendars), `notify` sends alerts and `export` writes your data somewhere else. There is no hook that submits an application. Every plugin in the registry was reviewed by the core maintainers and is pinned to an exact commit. Each row links the plugin's own repository, where its README explains setup.

## Write yours

The plugin guide is [PLUGINS.md](https://github.com/career-ops-hq/career-ops/blob/main/docs/PLUGINS.md) in the core repository. To start a new one from the template, run this in your career-ops folder:

```bash
node plugins.mjs new my-plugin
```

To list it in the registry, file a plugin registration issue and then a registry pull request in the core repository, as the guide describes.
