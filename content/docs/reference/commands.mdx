career-ops works through commands that you type in the AI coding CLI where you run it. `/career-ops` on its own shows them all; you can also paste a job URL or description directly, and career-ops detects it and runs the full pipeline. In Codex, slash commands are not guaranteed: use the same command names in a prompt instead.

None of them sends an application for you. It drafts and fills; it never submits. You press Submit.
