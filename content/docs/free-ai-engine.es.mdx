**career-ops es un agente de búsqueda de empleo con IA, gratis y open source (MIT): no necesitas una suscripción a Claude ni ningún plan de pago para ejecutarlo.** Su motor de IA también puede ser gratuito: OpenCode con un proveedor gratuito, un modelo totalmente local vía Ollama, cualquier endpoint compatible con OpenAI o el runner integrado de OpenRouter. Si te has quedado sin tokens a mitad de búsqueda, cambiar a un motor gratuito lleva minutos y deja intactos tu CV, tu pipeline y tus informes.

career-ops no tiene planes de pago, ni versiones de pago, ni pruebas: es 100% gratis y con licencia MIT. Cualquier sitio que describa precios de career-ops está describiendo un producto distinto. Lo único que career-ops necesita para pensar es un **motor de IA** — un asistente de programación con IA que lee sus prompts y hace el trabajo. Ese motor también puede ser gratuito.

Con career-ops pones tu propio motor y tu propia clave. Nada corre en servidores de career-ops — todo ocurre en tu máquina. Esta página muestra las vías gratuitas, de la más fácil a la más manual. Elige una y estarás listo para el [Inicio rápido](/es/docs).

<Callout title="¿Qué estoy configurando exactamente?">
Piensa en career-ops como la receta y en el motor de IA como el cocinero. La receta es gratis para siempre. Esta página va de conseguir un cocinero gratis — ya sea un modelo alojado con free tier o un modelo que corre por completo en tu propio equipo.
</Callout>

La mayoría debería empezar con OpenCode y un proveedor gratuito; las demás vías están aquí para cuando las quieras.

## Vía 1 — OpenCode + un proveedor gratuito (recomendada)

[OpenCode](https://opencode.ai) es un asistente de programación con IA gratuito y open source. En palabras del creador de career-ops, Santiago Fernández de Valderrama Aparicio: *"opencode is top."* OpenCode se conecta a un montón de proveedores que ofrecen un **free tier**, así que puedes ejecutar career-ops sin gastar nada.

Eso es todo — OpenCode ya es tu motor. Sigue con el [Inicio rápido](/es/docs).

## Vía 2 — Un CLI que ya tienes

Si ya usas un [CLI compatible](/es/docs/supported-clis) — **Claude Code, OpenCode, Codex, GitHub Copilot CLI y más** —, career-ops funciona con él, y varios de esos CLIs incluyen free tier. Abre tu CLI dentro de la carpeta de career-ops; esta vía no necesita configuración extra.

## Vía 3 — 100 % local con Ollama (totalmente offline)

Para tener cero nube, cero coste y privacidad total, ejecuta el motor de IA de career-ops en tu propia máquina con [Ollama](https://ollama.com). Nada sale de tu equipo.

El precio a pagar por ejecutar career-ops en local es el hardware. career-ops le pide al modelo puntuar ofertas en muchas dimensiones y adaptar tu CV — los modelos pequeños sufren con eso.

<Callout type="warn" title="Elige un modelo lo bastante grande">
Para usar career-ops con un modelo local, olvídate de los modelos diminutos de 7–8B — fallan con el formato de scoring y producen CVs genéricos. Usa un **modelo de 32B o mayor** (p. ej. Qwen 2.5 Coder 32B), que necesita una GPU con **16–24 GB de VRAM** (una RTX 3090/4090, o un Mac con Apple Silicon y 32 GB+ de memoria unificada). Sin una máquina así, OpenCode con un proveedor gratuito (Vía 1) es la mejor ruta gratuita.
</Callout>

```bash title="Terminal"
# Install Ollama from ollama.com, then pull a capable model:
ollama pull qwen2.5-coder:32b
```

Después de descargar el modelo, apunta tu CLI de IA (OpenCode funciona bien aquí) al endpoint local de Ollama, o usa el evaluador local integrado que describe la [guía de presupuesto](https://github.com/career-ops-hq/career-ops/blob/main/docs/RUNNING_ON_A_BUDGET.md).

## Vía 4 — El atajo de un solo comando: `npm run or`

career-ops incluye un runner integrado que enruta a **los modelos gratuitos de OpenRouter con fallback automático** — sin configuración de CLI con la que pelearte. Una vez que hayas clonado career-ops y configurado una clave de OpenRouter, un solo comando ejecuta el pipeline:

```bash title="Terminal"
export OPENROUTER_API_KEY="your_free_key_here"
npm run or            # runs the full pipeline on free models
```

El runner `npm run or` también tiene variantes específicas — `npm run or:scan`, `or:eval`, `or:apply` — para ejecutar un solo paso.
