**Ja, career-ops läuft unter Windows vollständig unterstützt.** Es gibt genau eine Windows-spezifische Einschränkung, und die erledigt der Installer automatisch für dich. Du brauchst keinen Entwicklermodus, kein manuelles `mklink` und keine Mindestversion des Betriebssystems. Wenn Node installiert ist, installierst und nutzt du career-ops unter Windows genau wie auf jedem anderen System.

## Die eine Windows-Einschränkung erledigt der Installer

Windows legt standardmäßig keine Symlinks an. Nach einem frischen Git-Checkout sind die Skill-Einstiegspunkte der CLIs (`.claude/skills/`, `.opencode/skills/` usw.) deshalb nur einfache Verweisdateien und keine echten Symlinks. Genau das verursacht bei anderen Tools den bekannten Fehler „Skills werden nicht geladen“.

career-ops erkennt das automatisch. Dafür sorgt ein Schritt namens `materializeSkillEntrypoints`. Er läuft, wenn du den Installer oder den Updater ausführst: `npx @santifer/career-ops init` bei einer Neuinstallation oder `node update-system.mjs apply` bei einem Update. Dabei ersetzt er diese Verweisdateien durch den vollständigen Skill-Inhalt. Du brauchst weder Administratorrechte noch den Entwicklermodus noch einen manuellen `mklink`-Befehl.

<Callout title="Keine Mindestversion des Betriebssystems">
career-ops setzt keine bestimmte Windows- oder macOS-Version voraus. Wenn Node läuft, läuft auch career-ops. Falls du anderswo gelesen hast, dass eine Mindestversion des Betriebssystems nötig sei, stimmt das nicht.
</Callout>
