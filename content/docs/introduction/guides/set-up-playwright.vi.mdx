## Cài đặt gói Playwright

Chạy `npm install` từ thư mục gốc của career-ops:

```bash title="Terminal"
npm install
```

Lệnh này cài Playwright cùng mọi phụ thuộc khác của dự án được khai báo trong `package.json`. Bạn có thể bỏ qua bước này nếu đã chạy nó trong lúc cài đặt ban đầu.

## Tải Chromium

Playwright cần một bản Chromium riêng để điều khiển. Thông thường trình cài đặt sẽ tự tải bản này ngay sau khi cài các phụ thuộc; nếu `npm run doctor` báo thiếu, hãy tải bằng lệnh:

```bash title="Terminal"
npx playwright install chromium
```

Đây là bước chỉ làm một lần. Bạn không cần lặp lại sau khi cập nhật `npm`.

## Cấu hình Playwright MCP

Playwright MCP cho phép Claude điều khiển trực tiếp trình duyệt trong bước `/career-ops apply` — mở các biểu mẫu ứng tuyển, đọc nhãn của từng trường và gợi ý câu trả lời.

### Đăng ký MCP server

Chạy lệnh sau từ thư mục gốc của career-ops để đăng ký Playwright MCP với Claude Code:

```bash title="Terminal"
claude mcp add --scope project playwright -- npx @playwright/mcp@latest
```

Đây là cách đăng ký một bước trong [tài liệu Playwright MCP](https://playwright.dev/docs/getting-started-mcp), có thêm `--scope project` để Claude Code ghi mục server vào `.mcp.json` ở thư mục gốc career-ops, một trong những tệp mà `npm run doctor` kiểm tra. Lần tới khi khởi động Claude Code tại đó, hãy chấp thuận server khi được hỏi.

Nếu muốn dùng cho mọi dự án, hãy chạy lệnh với `--scope user`. `npm run doctor` không đọc các server ở phạm vi người dùng, nên nó sẽ cảnh báo rằng không phát hiện được MCP dù Claude Code vẫn tải nó bình thường.

### Cấu hình thủ công (cách thay thế)

Nếu muốn tự cấu hình, hãy thêm mục sau vào `.mcp.json` ở thư mục gốc career-ops (tạo tệp nếu chưa có):

```json title=".mcp.json"
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp@latest"]
    }
  }
}
```

Hãy khởi động lại Claude Code sau khi lưu tệp và chấp thuận server khi được hỏi. Khi đó career-ops sẽ dùng được `browser_navigate` và `browser_snapshot` trong các phiên apply.

## Kiểm tra cài đặt

Chạy script doctor để xác nhận cả ba thành phần đã sẵn sàng:

```bash title="Terminal"
npm run doctor
```

Hãy tìm xác nhận rằng Playwright, Chromium và MCP server đều đã sẵn sàng. Nếu bước kiểm tra thành công, bạn đã cài đặt xong.

## Xem trình duyệt điền biểu mẫu

Theo mặc định, Playwright MCP mở một cửa sổ trình duyệt hiển thị (phần cài đặt ở trên không truyền `--headless`), nên bạn có thể thấy từng trang nó đọc và từng trường nó điền.

Để nó mở đơn ứng tuyển trong cửa sổ đó và điền toàn bộ biểu mẫu, hãy thêm một chỉ dẫn vào lệnh apply:

Nó soạn và điền, nhưng không bao giờ nộp. Bạn là người bấm Nộp.

Với Ashby, Playwright có thể kiểm tra biểu mẫu và giúp soạn câu trả lời, nhưng hãy hoàn tất và nộp đơn trong trình duyệt thông thường của hệ thống. Hãy xác minh trang thành công hoặc email xác nhận trước khi đánh dấu đơn ứng tuyển là đã nộp.

Nếu không có chỉ dẫn đó, career-ops vẫn dùng Playwright và MCP để đọc biểu mẫu và soạn câu trả lời cho bạn, trong cùng cửa sổ hiển thị đó.
