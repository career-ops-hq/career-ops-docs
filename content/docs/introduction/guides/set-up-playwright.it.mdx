## Installa il pacchetto Playwright

Esegui `npm install` dalla cartella principale di career-ops:

```bash title="Terminal"
npm install
```

Questo comando installa Playwright e tutte le altre dipendenze del progetto dichiarate in `package.json`. Salta questo passaggio se lo hai già eseguito durante la configurazione iniziale.

## Scarica Chromium

Playwright ha bisogno di una propria copia di Chromium da automatizzare. Di norma il programma di installazione la scarica automaticamente subito dopo le dipendenze; se `npm run doctor` segnala che manca, scaricala eseguendo:

```bash title="Terminal"
npx playwright install chromium
```

È un passaggio da fare una sola volta. Non devi ripeterlo dopo gli aggiornamenti di `npm`.

## Configura l'MCP di Playwright

L'MCP di Playwright permette a Claude di controllare direttamente il browser durante la fase `/career-ops apply`: apre i moduli di candidatura, legge le etichette dei campi e suggerisce le risposte.

### Registra il server MCP

Esegui questo comando dalla cartella principale di career-ops per registrare l'MCP di Playwright in Claude Code:

```bash title="Terminal"
claude mcp add --scope project playwright -- npx @playwright/mcp@latest
```

È il metodo di registrazione in un solo passaggio indicato nella [documentazione dell'MCP di Playwright](https://playwright.dev/docs/getting-started-mcp), con l'aggiunta di `--scope project` perché Claude Code scriva la voce del server in `.mcp.json` nella cartella principale di career-ops, uno dei file che `npm run doctor` controlla. La prossima volta che avvii Claude Code da lì, approva il server quando te lo chiede.

Se invece vuoi usarlo in tutti i progetti, esegui il comando con `--scope user`. `npm run doctor` non legge i server registrati a livello utente, quindi ti avviserà che non riesce a rilevare l'MCP anche se Claude Code lo carica.

### Configurazione manuale (alternativa)

Se preferisci configurarlo a mano, aggiungi la voce seguente a `.mcp.json` nella cartella principale di career-ops (crea il file se non esiste):

```json title=".mcp.json"
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp@latest"]
    }
  }
}
```

Dopo aver salvato il file, riavvia Claude Code e approva il server quando te lo chiede. A quel punto career-ops avrà accesso a `browser_navigate` e `browser_snapshot` durante le sessioni di apply.

## Verifica la configurazione

Esegui lo script doctor per confermare che tutti e tre i componenti siano al loro posto:

```bash title="Terminal"
npm run doctor
```

Controlla che Playwright, Chromium e il server MCP risultino tutti pronti. Se la verifica va a buon fine, la configurazione è completa.

## Guarda il browser mentre compila il modulo

Per impostazione predefinita l'MCP di Playwright apre una finestra del browser visibile (la configurazione qui sopra non passa `--headless`), così puoi vedere ogni pagina che legge e ogni campo che compila.

Per fargli aprire la candidatura in quella finestra e compilare l'intero modulo, aggiungi un'istruzione al comando apply:

Con Ashby, Playwright può esaminare il modulo e aiutarti a redigere le risposte, ma completa e invia la candidatura dal tuo normale browser di sistema. Prima di segnare la candidatura come inviata, verifica di aver ricevuto una pagina di conferma o un'email di conferma.

Senza quell'istruzione, career-ops usa comunque Playwright e l'MCP per leggere il modulo e redigere le tue risposte, nella stessa finestra visibile.
