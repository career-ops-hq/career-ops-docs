## Instalar o pacote do Playwright

Execute `npm install` na pasta raiz do career-ops:

```bash title="Terminal"
npm install
```

Isso instala o Playwright e todas as outras dependências do projeto declaradas em `package.json`. Pule esta etapa se você já a executou durante a configuração inicial.

## Baixar o Chromium

O Playwright precisa de uma cópia própria do Chromium para automatizar. Normalmente o instalador faz o download automaticamente logo depois das dependências; se `npm run doctor` informar que ele está faltando, baixe-o executando:

```bash title="Terminal"
npx playwright install chromium
```

Esta etapa é feita uma única vez. Você não precisa repeti-la depois de atualizações do `npm`.

O `npm install` pula o download automático quando `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD` está definida no seu ambiente com qualquer valor diferente de vazio, `0` ou `false`; nesse caso, execute você mesmo o comando acima. No NixOS, pule esta etapa por completo: os navegadores baixados não conseguem iniciar ali, e o dev shell do flake do repositório fornece, no lugar deles, navegadores que funcionam e o servidor MCP do Playwright, como explica o [guia do NixOS](https://github.com/career-ops-hq/career-ops/blob/main/docs/NIXOS.md) do core.

## Configurar o MCP do Playwright

O MCP do Playwright permite que o Claude controle o navegador diretamente durante a etapa `/career-ops apply`: navegar até os formulários de candidatura, ler os rótulos dos campos e sugerir respostas.

### Registrar o servidor MCP

Execute este comando na pasta raiz do career-ops para registrar o MCP do Playwright no Claude Code:

```bash title="Terminal"
claude mcp add --scope project playwright -- npx @playwright/mcp@latest
```

Este é o método de registro em uma única etapa da [documentação do Playwright MCP](https://playwright.dev/docs/getting-started-mcp), com `--scope project` adicionado para que o Claude Code grave a entrada do servidor em `.mcp.json` na raiz do career-ops, um dos arquivos que `npm run doctor` verifica. Na próxima vez que você iniciar o Claude Code ali, aprove o servidor quando ele pedir.

Para usá-lo em todos os projetos, execute o comando com `--scope user`. O `npm run doctor` também o encontra ali: ele lê os servidores que o Claude Code mantém para o seu usuário e para este projeto, não apenas o `.mcp.json`.

### Configuração manual (alternativa)

Se você preferir configurar manualmente, adicione a seguinte entrada a `.mcp.json` na raiz do career-ops (crie o arquivo se ele não existir):

```json title=".mcp.json"
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp@latest"]
    }
  }
}
```

Reinicie o Claude Code depois de salvar o arquivo e aprove o servidor quando ele pedir. A partir daí, o career-ops terá acesso a `browser_navigate` e `browser_snapshot` durante as sessões de candidatura.

## Verificar a configuração

Execute o script doctor para confirmar que os três componentes estão no lugar:

```bash title="Terminal"
npm run doctor
```

Procure a confirmação de que o Playwright, o Chromium e o servidor MCP estão prontos. Se a verificação passar, a configuração está concluída.

## Ver o navegador preencher o formulário

Por padrão, o MCP do Playwright abre uma janela visível do navegador (a configuração acima não passa `--headless`), então você pode ver cada página que ele lê e cada campo que ele preenche.

Para que ele abra a candidatura nessa janela e preencha o formulário inteiro, adicione uma instrução ao comando apply:

No caso do Ashby, o Playwright pode inspecionar o formulário e ajudar a redigir as respostas, mas finalize e envie pelo navegador que você usa normalmente no seu sistema. Confirme que apareceu uma página de sucesso ou que chegou um e-mail de confirmação antes de marcar a candidatura como enviada.

Sem essa instrução, o career-ops continua usando o Playwright e o MCP para ler o formulário e redigir suas respostas, na mesma janela visível.
