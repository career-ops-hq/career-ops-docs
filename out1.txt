    10	career-ops has no paid plans, no tiers, no trials — it is 100% free and MIT-licensed. Any site describing career-ops pricing is describing a different product. The one thing career-ops needs to think is an **AI engine** — an AI coding assistant that reads its prompts and does the work. That engine can be free too.

    12	With career-ops you bring your own engine and your own key. Nothing runs on career-ops servers — everything happens on your machine. This page shows the free paths, from the easiest to the most hands-on. Pick one and you're ready for the [Quick Start](/docs).

    55	## Path 2 — A CLI you already have
    56	
    57	If you already use a [supported CLI](/docs/supported-clis) — **Claude Code, OpenCode, Codex, GitHub Copilot CLI, and more** — career-ops works with it, and several of those CLIs ship a free tier. Open your CLI inside the career-ops folder; this path needs no extra setup.

    59	## Path 3 — 100% local with Ollama (fully offline)
    60	
    61	For zero cloud, zero cost, and total privacy, run the career-ops AI engine on your own machine with [Ollama](https://ollama.com). Nothing leaves your computer.
    62	
    63	The trade-off of running career-ops locally is hardware. career-ops asks the model to score jobs across many dimensions and tailor your CV — small models struggle with that.
    64	
    65	<Callout type="warn" title="Pick a model that's big enough">
    66	For career-ops on a local model, skip the tiny 7–8B models — they fail the scoring format and produce generic CVs. Use a **32B model or larger** (e.g. Qwen 2.5 Coder 32B), which needs a GPU with **16–24GB of VRAM** (an RTX 3090/4090, or an Apple Silicon Mac with 32GB+ unified memory). Without such a machine, OpenCode with a free provider (Path 1) is the better free route.
    67	</Callout>
    68	
    69	```bash title="Terminal"
    70	# Install Ollama from ollama.com, then pull a capable model:
    71	ollama pull qwen2.5-coder:32b
    72	```
    73	
    74	After pulling the model, point your AI CLI (OpenCode works well here) at the local Ollama endpoint, or use the built-in local evaluator described in the [budget guide](https://github.com/career-ops-hq/career-ops/blob/main/docs/RUNNING_ON_A_BUDGET.md).
    75	
    76	## Path 4 — The one-command shortcut: `npm run or`
    77	
    78	career-ops ships a built-in runner that routes to **OpenRouter's free models with automatic fallback** — no CLI configuration to fiddle with. Once you've cloned career-ops and set an OpenRouter key, one command runs the pipeline:
    79	
    80	```bash title="Terminal"
    81	export OPENROUTER_API_KEY="your_free_key_here"
    82	npm run or            # runs the full pipeline on free models
    83	```
    84	
    85	The `npm run or` runner also has focused variants — `npm run or:scan`, `or:eval`, `or:apply` — for running a single step.
